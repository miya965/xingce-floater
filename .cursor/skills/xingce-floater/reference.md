# 发布边界

可以放上 GitHub 的：

- `Sources/`、`Tests/`、`scripts/`、`Database/schema.sql`
- `Fixtures/sample-bank.json` 和 `Fixtures/images/`（原创示例）
- `.cursor/skills/xingce-floater/`

不要放上 GitHub 的：

- 任何第三方题库文件、题目导出、解析或配图
- `build/` 里的应用包
- 本机 Node 运行时
- 桌面上单独放着的刷题服务目录

本机服务如果本来就在它自己的公开仓库里，让读者去那个仓库按它的许可证取得。不要把题库再打包进这个项目。
